# Sub2API 桌面卡片：结构 × 配色，第二轮探索

2026-10-22 · D04 · 已选定的视觉交互稿与本地实现

入口：[视觉探索交互稿](visual-style-exploration.html)。每类提供 3 组配色，均同时展示额度卡 2×2、额度卡 2×4、趋势卡 2×4、趋势卡 4×4。支持深浅桌面、额度正常/偏低/用尽/未知/断网、趋势 7/30 天、请求/费用、选择日期，以及在浏览器里记录多个候选。

- 用户认可「一种结构 × 多套配色」的选择方式。这是后续产品设计应保留的原则：结构控制字形、形状、边界、材料与图表；配色控制底色、文字、双强调色和状态色。选择按 `(structureId, paletteId)` 组合记录，不把某种结构绑定成唯一颜色。本稿先提供逐套校准的 3 组配色，并非让任意色板未经校准地互换。

## 四种卡片的适配边界

- 额度卡 2×2：保留账号、额度、状态、时间；晨雾渐层和轻铝面板使用环形额度，软垫模块和酒标徽章使用带数字的独立徽章，口袋液晶使用点阵额度尺。未知显示 `--`，不当成 0%；未知时不显示已知进度。
- 额度卡 2×4：双账号分区，数字、状态、分隔线和底部时间均使用同套视觉。
- 趋势卡 2×4：紧凑排版，保留账号、7/30 天、请求/费用、图表与选中日期；单独控制字号和间距。
- 趋势卡 4×4：放大图表和关键数字，沿用中卡的指标交互与配色。费用使用第二强调色，避免沿用固定暖色导致主题不协调。
- 所有方向都保留文字状态；断网时保留上次数据并标明时间。额度未知与用量趋势是不同的数据维度，前者未知不清空已有历史用量。
- 卡片尺寸为布局比例示意，窄屏预览会收缩宽度；最终留白、裁切、字体与环形/图表能力需在 HarmonyOS API 22 真机确认。
